# Rare UI design

1. Read `DESIGN.md` at the repo root in full. It holds the tokens, the signature surfaces and the "How Swami likes it" section.
2. Follow its "How to work" steps: look at the reference, build small in the Rare UI language, screenshot it yourself at real size, then iterate in small steps.
3. Before reporting, check the result against "What gets rejected". If any item matches, fix it first.
4. When the user approves a new pattern, add it to `DESIGN.md` under the right heading.
